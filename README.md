# Social Post CRUD

A responsive social post CRUD application built with Express.js, MongoDB, Mongoose, and EJS. Users can create, view, update, and delete posts through a clean and responsive interface.

---

## Features

- Create new posts
- View all posts
- View individual post details
- Edit existing posts
- Delete posts
- MongoDB database integration
- Express.js backend
- EJS templating engine
- Method Override for PATCH and DELETE requests
- Responsive Dark UI

---

## Installation

### Clone Repository

```bash
git clone https://github.com/your-username/social-post-crud.git
```

### Move Into Project Directory

```bash
cd social-post-crud
```

### Install Dependencies

```bash
npm install
```

### Start Server

```bash
node app.js
```

Server will run on:

```text
http://localhost:3000
```

## CRUD Operations

| Operation | Route |
|-----------|--------|
| Create Post | POST /posts |
| Read All Posts | GET /posts |
| Read Single Post | GET /posts/:id |
| Update Post | PATCH /posts/:id |
| Delete Post | DELETE /posts/:id |
